# Off the Hook – Website

High-converting landing page for **Off the Hook** – fresh fish, quality chickens and free-range eggs delivered across Cape Town northern and southern suburbs.

## Files
- `index.html` – Main page (includes editable products section)
- `styles.css` – All styling (mobile-first)
- `script.js` – Mobile menu + smooth scroll
- `logo.png` – Your Off the Hook logo
